## Blog 1 - DS in The Real World
Data science is often framed as a purely technical domain—a realm of clean pipelines, fast algorithms, and optimized models. But when the data we analyze is generated by human behavior, technical skill alone isn't enough. Modeling social topics matters because numbers allow us to observe societal patterns that would otherwise remain invisible. Through data, we can track systemic healthcare inequities, analyze urban resource distribution, or observe how information spreads across communities. By modeling human interactions and social systems, we move from vague intuition toward concrete evidence, giving us the tools to address complex real-world challenges with greater accuracy.

However, using data derived from human lives carries profound ethical weight. Behind every row in a dataframe, point on a scatter plot, or weight in a neural network is a real person with rights, privacy, and real-world consequences tied to the outcomes of those systems. Data is never neutral; it inherits the biases, historical context, and power dynamics of the environment in which it was gathered. Treating people's data strictly as raw computational input risks automating discrimination, reinforcing systemic inequities, and breaching trust. As practitioners, our fundamental responsibility is to interrogate our datasets, audit models for bias, protect user privacy, and remain relentlessly critical of the assumptions built directly into our code.

This is precisely why studying data science within its social context matters. Technical mastery in tools like Python means very little if we lack the social literacy required to interpret what the outputs actually mean in human terms. Through this course, I hope to better understand how to design technical workflows that actively account for human context. I want to learn how to ask better foundational questions before collecting data, recognize the hidden blind spots in human-centered datasets, and develop models that respect human complexity rather than flattening it. Data science shouldn't exist in a vacuum; it gains its true value when grounded in human reality.

## Blog 2 - Project Portfolio (Part 1) ~ Lessons from Movie Metadata
Film is an inherently qualitative medium, yet as data scientists, we routinely attempt to capture its impact through quantitative attributes like runtime minutes and 10-point audience rating scales. In my recent Exploratory Data Analysis (EDA) project querying The Movie Database (TMDB) REST API, I set out to evaluate how film length influences audience satisfaction across distinct cinematic genres. Building an automated pipeline in Python to ingest, clean, and visualize movie metadata revealed fascinating trends—such as Animation maintaining top-tier audience scores (>9.0) at concise runtimes under 100 minutes, while Science Fiction demonstrated extreme rating variance, swinging from a 4.0 score at 91 minutes to an 8.6 at 157 minutes.

However, translating artistic expression into a structured dataframe highlights the delicate balance between technical aggregation and lost nuance. Operationalizing a complex, multi-layered movie by assigning it a single "primary genre" tag inevitably flattens multi-genre works, masking how sub-genres or hybrid narratives influence audience scores. Furthermore, crowd-sourced ratings on platforms like TMDB carry inherent demographic biases, representing a specific digital sub-community rather than a true random sample of global moviegoers. Filtering low vote thresholds and handling missing values taught me that data cleaning is not merely a routine syntax exercise, but an active decision-making process that defines the ethical boundaries of our analytical findings.

Executing this project from raw API endpoints to visual storytelling reinforced that data science gains its true power when technical execution is paired with critical reflection. Translating raw scatter plots and bar graphs into meaningful narrative insights demonstrated how easily numbers can be misinterpreted without domain context and baseline comparisons. Whether analyzing audience behavior in entertainment or evaluating biological datasets in medicine, the fundamental lesson remains the same: analytical mastery requires us to interrogate our assumptions, respect the limits of our data, and never lose sight of the real-world complexity behind the numbers.

## Blog 3 - Project Portfolio (Part 2) ~ Quantifying Esports & Demographic Trends in Valorant

Esports is a modern phenomenon built on split-second mechanics, strategic positioning, and evolving tactical metas, yet as data scientists, we routinely attempt to model player performance through quantitative attributes like Average Combat Score (ACS) and discrete agent role categories. In my recent machine learning project leveraging data extracted via the VLRdevAPI, I set out to investigate how player age influences performance metrics and in-game role specializations (Duelist, Initiator, Controller, and Sentinel) across professional Valorant rosters. Developing a Python pipeline to ingest player profiles, clean missing values, and train both Linear Regression and Decision Tree models revealed intriguing patterns—such as Decision Tree splits grouping younger players into aggressive opening roles, while linear modeling of age versus ACS produced an R-squared score of -0.09, proving that raw combat score is far too complex to be captured by age alone.

However, translating high-stakes tactical gameplay into a structured dataframe highlights the delicate balance between statistical modeling and lost competitive nuance. Operationalizing a player by assigning them a single "primary role" tag inevitably oversimplifies flex players who adapt their agent selections based on specific map layouts, opponent compositions, or mid-season meta patches. Furthermore, using player demographics to predict performance carries real-world implications; relying on age boundaries in machine learning models could introduce ageist biases into scouting and roster construction, penalizing veteran players who bring invaluable intangible assets like communication, leadership, and mid-round shot-calling that no API endpoint captures.

Executing this machine learning workflow from raw REST API endpoints to visual tree diagrams reinforced that technical modeling gains its true value when paired with critical domain reflection. Translating positive linear coefficients (+1.60) and 30% classification accuracy into meaningful insights demonstrated how easily statistical outputs can be misinterpreted without understanding the surrounding environment. Whether predicting player roles in competitive gaming or analyzing user behavior in complex digital ecosystems, the fundamental lesson remains the same: true analytical rigor requires us to look beyond simple metric scores, respect the boundaries of our models, and never lose sight of the human elements behind the data points.
